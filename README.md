# ScrollArcade

**TikTok for mini-games.**

Swipe (or scroll) through an endless vertical feed of bite-sized interactive experiences. Reaction tests, memory matches, sequence challenges, vibe selectors, typing races and more.

Inspired by the viral idea of a "TikTok for vibecoded minigames".

## Features

- **Vertical snap scrolling** — full-screen cards, one game at a time
- **6 mini-games / experiences**
  - Reaction Time Tester
  - Click Frenzy (CPS counter + particles)
  - Memory Match
  - Sequence Master (Simon-style)
  - Vibe Selector + personalized quotes
  - Speed Typing
- **Local high scores** (persisted in localStorage)
- **Zero backend / zero signup** — pure client-side fun
- **Beautiful dark neon aesthetic** with Tailwind CSS
- Fully responsive

## Tech Stack

- Next.js 16 (App Router)
- React 19
- TypeScript
- Tailwind CSS v4

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy

Deploy instantly on [Vercel](https://vercel.com).

```bash
npx vercel
```
